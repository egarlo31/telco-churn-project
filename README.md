# Telco Customer Churn Prediction

## Objective

The objective is to predict which customers are likely to cancel their telecommunications service.

The model should prioritize identifying potencial churners while controlling the number of customers incorrectly classified as churners.

## ML objective

Build a binary classification system that predicts:
- 0: Customer remains
- 1: Customer churns

The primary evaluation metrics will be recall, precision and F1-score for class 1. The final decision threshold will be selected using business costs, not just accuracy.
